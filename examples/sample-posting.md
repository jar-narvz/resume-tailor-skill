# Backend Software Engineer Intern, Summer 2027 — Globex Logistics (made-up posting)

**Location:** San Francisco, CA (hybrid) · **Team:** Shipment Platform

Globex moves freight for 2,000 retailers. The Shipment Platform team owns
the APIs and data pipelines that track every package from warehouse to
doorstep.

## What you'll do
- Build and maintain REST APIs in Go and Python that power shipment tracking
- Design PostgreSQL schemas and write efficient SQL for high-volume event data
- Improve the reliability of distributed services: retries, idempotency, failover
- Write unit and integration tests, and keep CI green
- Partner with data engineers on data-quality checks for tracking events

## What we're looking for
- Pursuing a BS in Computer Science or a related field, graduating 2027 or 2028
- Experience with at least one of Go, Python, or Java
- Familiarity with SQL and relational databases (PostgreSQL preferred)
- Understanding of distributed systems fundamentals
- Experience with Docker and CI/CD

## Nice to have
- Kafka or another message queue
- Kubernetes
- Experience with consensus protocols (Raft, Paxos)
